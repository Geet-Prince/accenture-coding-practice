# 04 — Hashing & Frequency

## Priority: A — HIGH PRIORITY

## Historical Importance
Hashing is embedded in many Accenture questions:
- Most Frequent Vowel (frequency map over 5 vowels)
- Anagram Check (frequency comparison)
- Autobiographical Number (digit frequency)
- Duplicate detection

## Common Mistakes
- Using int[] for char frequency when string contains uppercase
- Not lowercasing before frequency count
