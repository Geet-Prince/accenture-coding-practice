# 03 — Math & Numbers

## Priority: S — MUST MASTER

## Historical Importance
Difference of Sum (4-year repeat), Decimal to N-Base (2-year), Max Exponent of 2 (3-year), Autobiographical Number (3-year).

## Study Order
1. Divisibility sums (Difference of Sum pattern)
2. Base conversion (Decimal to any base)
3. Powers of 2 (Max Exponent)
4. Armstrong, Perfect numbers (digit manipulation)
5. Prime checking (O(sqrt N))
6. GCD/LCM

## Common Mistakes
- int overflow when computing large factorials/sums → use long
- Base conversion: mapping remainder > 9 to A-Z requires ASCII math
- Armstrong: need to extract each digit individually
