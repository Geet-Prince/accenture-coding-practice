# 01 — Arrays

## Priority: S — MUST MASTER

## Why This Topic Matters
Arrays appear in **every** Accenture coding round from 2020–2026.  
Historical questions like Rat Count House (repeated 4 times) and Large Small Sum (3 times) are purely array problems.

## Study Order
1. Traversal (basics)
2. Indexing (even/odd positions — key Accenture pattern)
3. Min/Max + Second Largest/Smallest
4. Prefix Sum
5. Equilibrium Index (prefix sum application)
6. Kadane's Algorithm (max subarray)
7. Frequency + Duplicates
8. Sorting + Searching
9. Two Pointers
10. Historical Questions

## Accenture Relevance
- **LargeSmallSum** uses even/odd indexing + sorting
- **RatCountHouse** uses prefix accumulation
- **EquilibriumIndex** uses prefix sum
- **ProductSmallestPair** uses sorting
- **SuperiorElements** uses reverse traversal

## Common Mistakes
- Off-by-one in index access
- Returning wrong error code (0 vs -1)
- Not handling empty/null arrays
- Using `int` instead of `long` for large sums
