## [1.0.0] - 2025-08-13

### 🎉 Initial Release

First official release of the **Accenture Coding Prep** repository designed for the **2027 Accenture Placement Drive** targeting **ASE (Associate Software Engineer)** and **AASE (Advanced Associate Software Engineer)** roles.

#### Key Features Included:
- 📚 **76+ Java Coding Problems:** Sourced and reconstructed from actual Accenture placement drives conducted between 2020 and 2026.
- ⚡ **Automated PowerShell Test Runner:** Millisecond-level local test evaluation script (`scripts/run-test.ps1`) executing visible and hidden JSON test suites.
- 🖥️ **VS Code Integration:** Native `tasks.json` integration for single-shortcut execution (`Ctrl + Shift + B` / `Ctrl + Alt + T`).
- 📂 **14 Topic-Wise Directories:** Structured progression from S-Tier fundamentals (Arrays, Strings, Math, Hashing) to Pseudocode and advanced practice.
- ⏱️ **10 Timed Mock Tests:** 45-minute exam simulations matching real Accenture assessment constraints.
- 🗺️ **30-Day Study Roadmap:** Structured daily study plan optimized for maximum ROI.
- 🤖 **AI Teacher Framework:** Graduated prompt system for Copilot/ChatGPT (`AI-TEACHER.md`) providing progressive hints without revealing direct code.
- 📊 **Progress Tracking System:** Interactive markdown progression log (`PROGRESS.md`) to measure speed, accuracy, and weak topics.
